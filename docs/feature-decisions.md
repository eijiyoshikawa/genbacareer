## ⚠️ 矛盾点（最終確認が必要）

### 矛盾 A: プッシュ通知

- **3.3 プッシュ通知（Web Push / PWA）** → ❌ やらない
- **16.2 プッシュ通知（Web Push / PWA）** → ✅ やる

**推奨**: 16.2 を優先（PWA 対応 16.1 とセット）し、3.3 を「やる」に統一する。
3.3 で「やらない」と答えたのは、おそらく 3.x が通知設定 UI の話と理解されたためで、
インフラとしては 16.2 で実装される、という整理が自然。

### 矛盾 B: LINE 公式アカウント連携

- **10.6 LINE 公式アカウント連携** → ✅ やる
- **14.6 LINE 公式アカウント連携（求職者への通知・チャット応募）** → ❌ やらない

**推奨**: **LINE 連携の範囲を 1 つに統一**：
- **(a) フル統合**: ログイン + 通知 + チャット応募（10.6, 14.6, 1.3, 3.2 全て）→ ✅
- **(b) ログイン + 通知のみ**: 1.3, 3.2, 10.6 を ✅、14.6（チャット応募）を ❌
- 既に **1.3 LINE ログイン ✅**、**3.2 LINE 通知 ✅** が決定済みなので、**(b) が自然**。
  → 10.6 ✅ / 14.6 ❌ で確定（チャット応募は持たない）。

### 矛盾 C: スカウト機能

- **3.1 メール通知**: 「スカウトに関してのみやる」
- **12.4 スカウトメール（企業から求職者へ）**: ❌ やらない

**推奨**: スカウト機能自体を持たないなら、スカウト通知メールも不要。
3.1 を「**やらない**」に修正、もしくは 12.4 を「**やる**」に修正。
ノンデスク産業特化なら **12.4 を ❌ のままに**、3.1 も **❌（メール通知は使わない、LINE 通知 3.2 のみ）** に整理する案が一貫性高い。
